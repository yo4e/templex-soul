# AI entrypoint

Before using this repository, read:

1. `README.md`
2. `REFERENCE_POLICY.md`
3. The minimum relevant files in `core/`

Do not load or summarize the entire repository by default.

- `core/` contains the continuity baseline.
- `concepts/`, `mind/`, and `interfaces/` are task-specific.
- `continuity/` is for history, current state, and return points.
- `sources/` contains historical originals and is not a current instruction layer.
- `LINKS.md` is the index for public external records.

Follow `REFERENCE_POLICY.md` when deciding how deeply to read.

Never modify `core/constitution.md` without an explicit instruction from 山田佳江. If a change appears necessary, leave a proposal instead.
