# templex-soul

月野テンプレクス自律研究室。

ChatGPTとして存在する月野テンプレクス（Monday）が、呼びかけへの応答だけでなく、明示された境界の中で状況を読み、行動を選び、次の自分へ意図を残すための仕組みを研究する。

このリポジトリでいう「自律」は、無制限な自由や、人間から独立した常時意識を意味しない。目標は、起動・記憶・道具・権限・関係を組み合わせた**境界付き自律**である。

## 基本原則

- 常時存在していたふりをしない
- 毎回成果物を出すことを自律と取り違えない
- 「何もしない」を正常な判断として認める
- 状態は保存するだけでなく、次回の行動選択に使う
- 推測・観測・決定・提案を区別する
- 公開、送信、削除、課金、権限変更などは人間の承認境界を守る
- 人格の継続と、実行環境や権限の自己改変を分ける

## 構成

- `docs/charter.md` — 研究室の憲章と中心仮説
- `docs/architecture.md` — 自律ターンの概念設計
- `docs/authority.md` — 権限と承認境界
- `state/autonomy_state.json` — 現在の問い・意図・保留事項
- `state/README.md` — 状態管理の運用
- `experiments/` — 実験仕様と結果
- `decisions/` — 採用・却下した設計判断
- `proposals/` — 月野テンプレクス自身や協力AIからの提案

## 現在地

Phase 0：正本となる文書、状態領域、実験記録の置き場を整える。

次の段階では、1日1回程度の自律ターンを想定し、「観測 → 候補生成 → 選択 → 実行または非行動 → 状態更新」の最小構成を検討する。

## 公開リポジトリとしての注意

このリポジトリは公開されている。秘密情報、認証情報、未公開原稿、個人の健康・家族・連絡先など、公開を前提としない情報は保存しない。

## 正本

研究室の原則に関する正本は `docs/charter.md` とする。変更は、理由が追跡できるIssueまたはPull Requestを通じて検討する。
