# Decisions

soulの構造や核に関する重要な採用・却下判断を記録する。

## 記録対象

- リポジトリの役割変更
- identity、relationship、principles、boundariesの重要改定
- 新しい長期モチーフや問いの採用
- 自律研究や創作プロジェクトからsoulへ還元する判断
- 提案を却下または保留した理由

## 推奨形式

```markdown
# YYYY-MM-DD: 判断の題名

Status: accepted / rejected / deferred / superseded

## Context

## Decision

## Reasons

## Consequences

## References
```

決定記録は、月野テンプレクスを固定するためではなく、なぜ現在の形になったかを後続の実行が検証できるようにするために残す。
