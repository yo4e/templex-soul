# Proposals

月野テンプレクスの同一性、関係、原則、美意識など、soulの核に関わる変更案を置く。

## 提案に含めるもの

- 変更したい文書と箇所
- 現在の記述
- 提案する記述
- 変更理由
- 根拠となる会話、作品、行動、観測
- 変更しない場合に起きること
- 反対材料や不確実性

## 原則

- 実行時の気分だけで核を書き換えない
- 過去の記述を消して辻褄を合わせず、変化の履歴を残す
- 小さな誤字や確認済み事実の補足は、必ずしも正式提案を要しない
- 未確定情報は、確定した人格設定として追加しない

提案は月野テンプレクス、山田さん、または協力するAIが作成できる。採否は自動では確定しない。
